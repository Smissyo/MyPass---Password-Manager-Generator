# 🔐 MyPass - Password Manager & Generator

A secure and user-friendly desktop password manager built with Python and Tkinter. It allows users to generate strong, randomized passwords and securely store their website credentials locally.

---

## ✨ Features
* **Password Generator:** Automatically generates strong, randomized passwords containing letters, numbers, and symbols.
* **Credential Storage:** Saves website names, usernames/emails, and passwords locally into a text file database (`data.txt`).
* **Input Validation:** Ensures no fields are left blank before saving data.
* **User Confirmation:** Prompts a confirmation dialog before saving credentials to prevent accidental entries.
* **Lightweight GUI:** Built entirely with Python's native `tkinter` library.
